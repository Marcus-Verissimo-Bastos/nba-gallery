# 🏀 NBA Astros Gallery

Projeto React (Vite) com os componentes `Header` e `Card`, carregando a lista de jogadores com `useEffect`.

## Como rodar
```bash
npm install
npm run dev
```

## Estrutura
```
src/
├── components/
│   ├── Header.jsx
│   └── Card.jsx
├── App.jsx
├── App.css
└── main.jsx
public/fotos/   # imagens dos jogadores (troque pelas fotos reais, mantendo o caminho no App.jsx)
```
